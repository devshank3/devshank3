# Hi, I'm Shankar Hariharan

Software engineer at [Siemens Healthineers](https://www.siemens-healthineers.com/), working in Magnetic Resonance department. I write scanner-side software for [myExam Companion](https://www.siemens-healthineers.com/magnetic-resonance-imaging/technologies-and-innovations/my-exam-companion) — the layer that lives on the MRI system and helps exams run with less friction and a clearer workflow.

Most of that work is backend: services, data, and the glue that keeps scanner software reliable. 

[shankr.dev](https://shankr.dev) · [Circuit Notes](https://shankr.dev/blog/) · [Reading Room](https://shankr.dev/domain/) · [Projects](https://shankr.dev/projects/)

---

## Primary tech stack

The stack I use most days at work — mostly backend systems: cloud services, APIs, and data. Desktop UI and complementary frontend work show up when the scanner needs them. Agentic LLM engineering here means landing agents inside those existing applications, not building demos on the side.

`Azure` · `.NET` · `ASP.NET` · `PostgreSQL` · `Avalonia` · `WPF` · `Frontend frameworks` · `Agentic LLM engineering`

## Domain topics

Subjects I can go deep on: how MRI exams actually run, how medical images are produced and used, and the computer vision around them.

`MRI` · `Medical imaging` · `Computer vision`

## Personal projects & exploration

Outside work I like building things end to end — agents, web apps, and small hardware sitting on a desk. Raspberry Pi projects and 3D printing are how a lot of those ideas leave the screen.

`Python` · `React` · `Astro` · `Raspberry Pi` · `3D printing`

I hold a Bachelor's degree in Electronics and Instrumentation Engineering.
